# PadPlay 用語集(日本語 / English)

> パッケージに入っている文書(`Documentation~`)の Web の写しです。SDK 0.2.0。[文書の一覧](./) · [問い合わせ](https://github.com/Petaf000/PadPlay)

PadPlay のエディタの窓・Inspector・実行時の表示を日本語で出す時の用語です。
言語は Welcome の窓の右上か *Preferences → PadPlay* で選べます(Auto = Unity エディタの言語)。
遊ぶ人が見る文字(QR の下の案内・Status View)は PadPlayHost の *Connection → Display Language*(Auto = OS の言語)。

- Inspector の項目の名前(Max Players・Drag Threshold Mode など)は、コードのフィールドの名前と同じ英語のままです。説明(Tooltip)だけが日本語になります。
- メニューの道筋(*Window → PadPlay → …*・*GameObject → PadPlay → PadPlay Setup*)・Console のログ・例外・Debugger のイベントの記録は英語のままです(検索と問い合わせのため)。
- 文書(Quick Start・Concepts・Debugging)は英語です。
