## English

**PadPlay** turns a smartphone or tablet into a controller with its own screen (touch, gyro, on-screen buttons, rumble and a private view of the game) for PC games made with Unity.
Players scan a QR code with one generic app; no per-game app and no special hardware.

This repository is the **public support place** for PadPlay. It does **not** contain the source code of the SDK or the app.

### Products

| Product | What | Where to get it |
|---|---|---|
| **PadPlay SDK** | Unity package for game developers (video second screen, multiple players). | Unity Asset Store — *store page coming soon* |
| **PadPlay Lite** | Free version of the SDK (one player, no video). | Unity Asset Store — *store page coming soon* |
| **PadPlay** (app) | The phone app players use to connect to a game. | Google Play — *coming soon*. App Store — *later* |

1. Check the [FAQ](FAQ.md) and [Known issues](KNOWN_ISSUES.md).
2. **Bug?** Open an [issue](https://github.com/Petaf000/PadPlay/issues/new/choose) with the *Bug report* form. Please fill in the Unity version, OS, GPU, phone model, app version and the result of *Connection Check*.

4. **Privacy or anything you do not want to post publicly**: petaf570@gmail.com

Issues and Discussions are public. Do not post personal information, keys or passwords.

## 日本語

**PadPlay** は、スマートフォン・タブレットを、Unity で作った PC のゲームの「画面つきコントローラー」(タッチ・ジャイロ・画面のボタン・振動・その人だけのゲームの画面)にします。
遊ぶ人は 1 つの汎用アプリで QR を読むだけです。ゲームごとのアプリや特別な機材は要りません。

このリポジトリは PadPlay の**問い合わせ用の公開の場所**です。SDK とアプリのソースコードは**入っていません**。

### 製品

| 製品 | 内容 | 入手先 |
|---|---|---|
| **PadPlay SDK** | ゲーム開発者向けの Unity パッケージ(第二画面の映像・複数人)。 | Unity Asset Store — *ストアのページは準備中* |
| **PadPlay Lite** | SDK の無料版(1 人・映像なし)。 | Unity Asset Store — *ストアのページは準備中* |
| **PadPlay**(アプリ) | 遊ぶ人がゲームにつなぐためのスマホのアプリ。 | Google Play — *準備中*。App Store — *その後* |
