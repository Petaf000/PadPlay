## English

**PadPlay** turns a smartphone or tablet into a controller with its own screen (touch, gyro, on-screen buttons, vibration and a private view of the game) for PC games made with Unity.
Players scan a QR code with one free app; no per-game app and no special hardware.

This repository is the **public support place** for PadPlay. It does **not** contain the source code of the SDK or the app.

### Products

| Product | What | Where to get it |
|---|---|---|
| **PadPlay SDK** | Unity package for game developers: touch, gamepad, gyro, on-screen buttons, vibration and second-screen video. | Unity Asset Store — *coming soon* |
| **PadPlay Lite** | Free edition of the SDK. Everything except second-screen video, with the same number of players. | Unity Asset Store — *coming soon* |
| **PadPlay** (app) | The free phone app players use to join a game. One app works with every PadPlay game. | Google Play — *coming soon*. App Store — *coming soon* |

### Getting help

1. Check the [FAQ](FAQ.md), [Known issues](KNOWN_ISSUES.md) and the [documentation](https://petaf.dev/padplay/docs/).
2. **Bug (game developers)**: open an [issue](https://github.com/Petaf000/PadPlay/issues/new/choose) with the *Bug report* form and paste the reports:
   - PC: in the Unity Editor, *Window → PadPlay → PadPlay Debug → Report → Collect a report*. In a built game, the Debug Overlay (F3, then F9) saves the same report.
   - Phone: in the PadPlay app, *About → Report a problem → Copy*.

   Both reports show the same session code, so they can be matched. Names, folders, keys, the network name and public addresses are taken out.
3. **Problem with the app (players)**: use the *Problem with the PadPlay app* form, or *Send by email* in the app.
4. **Question or idea?** Use [Discussions](https://github.com/Petaf000/PadPlay/discussions), or the *Question* / *Feature request* forms.
5. **Privacy, or anything you do not want to post publicly**: petaf570@gmail.com ([contact page](https://petaf.dev/contact/))

Issues and Discussions are public. Do not post personal information, keys or passwords. English or Japanese is fine.

## 日本語

**PadPlay** は、スマートフォン・タブレットを、Unity で作った PC のゲームの「画面つきコントローラー」(タッチ・ジャイロ・画面のボタン・振動・その人だけのゲームの画面)にします。
遊ぶ人は 1 つの無料アプリで QR を読むだけです。ゲームごとのアプリや特別な機材は要りません。

このリポジトリは PadPlay の**問い合わせ用の公開の場所**です。SDK とアプリのソースコードは**入っていません**。

### 製品

| 製品 | 内容 | 入手先 |
|---|---|---|
| **PadPlay SDK** | ゲーム開発者向けの Unity パッケージ。タッチ・ゲームパッド・ジャイロ・画面のボタン・振動・第二画面の映像。 | Unity Asset Store — *準備中* |
| **PadPlay Lite** | SDK の無料版。第二画面の映像のほかは同じで、人数も同じです。 | Unity Asset Store — *準備中* |
| **PadPlay**(アプリ) | 遊ぶ人がゲームにつなぐための無料のスマホのアプリ。1 つのアプリでどの PadPlay のゲームにもつながります。 | Google Play — *準備中*。App Store — *準備中* |

### 問い合わせの仕方

1. まず [FAQ](FAQ.md)・[既知の問題](KNOWN_ISSUES.md)・[文書](https://petaf.dev/padplay/docs/ja/) をご覧ください。
2. **不具合(ゲームの開発者)**: [Issue](https://github.com/Petaf000/PadPlay/issues/new/choose) の「Bug report」のフォームを開き、報告を貼ってください。
   - PC: Unity エディタの *Window → PadPlay → PadPlay Debug →「報告」→「報告をまとめる」*。ビルドしたゲームでは Debug Overlay(F3 の後に F9)で同じ報告を保存できます。
   - スマホ: PadPlay のアプリの「このアプリについて」→「問題を報告する」→「コピー」。

   2 つの報告には同じ照合の番号が出るので、突き合わせられます。名前・フォルダ・鍵・ネットワークの名前・外のアドレスは消してあります。
3. **アプリの問題(遊ぶ人)**: 「PadPlay のアプリの問題」のフォームか、アプリの「メールで送る」で。
4. **質問・要望**は [Discussions](https://github.com/Petaf000/PadPlay/discussions)、または「Question」「Feature request」のフォームで。
5. **プライバシーのこと・公開の場に書きたくないこと**: petaf570@gmail.com([お問い合わせのページ](https://petaf.dev/ja/contact/))

Issue と Discussions はだれでも読めます。個人情報・鍵・パスワードは書かないでください。日本語でも英語でも大丈夫です。
